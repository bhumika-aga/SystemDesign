System Design Notebook

Picture-first notes for every lecture in the course. Each chapter has analogies, diagrams, the detail from the video, extra reading, and revision questions at the end.

To add a chapter's notes, save the HTML file in this folder (or a subfolder such as LLD/), then put its path in that chapter's file field in the CHAPTERS list near the bottom of index.html. The chapter turns into a link and the progress bars update.
